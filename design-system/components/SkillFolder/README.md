# SkillFolder

Pasta de skills: fechada mostra papéis espiando; ao clicar a aba sobe, a frente tomba e os mini-cards saem com mola, organizando-se em grade acima.

- `title`, `index`, `items` (`{ name, ext, category, glyph? }`). `glyph` padrão = duas primeiras letras.
- Colunas se ajustam à largura (1–3); quantos itens quiser. Use `.mf-folder-grid` para o conjunto das quatro pastas.
- Sem porcentagens de domínio nem logos coloridos.
