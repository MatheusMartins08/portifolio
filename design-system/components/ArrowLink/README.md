# ArrowLink

Link de texto com seta: underline de hairline que se desenha em terracota no hover, texto desloca 2px.

- Use para LinkedIn ↗, GitHub ↗, *Case study →*, *View my GitHub ↗* (`size="lg"`).
- Links `http(s)` abrem em nova aba e anunciam isso a leitores de tela (`newTabLabel`).
- Seta `arrow-up-right` = externo, `arrow-right` = navegação interna.
