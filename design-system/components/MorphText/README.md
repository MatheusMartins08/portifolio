# MorphText

Frase dinâmica da Hero: as letras em comum entre duas frases viajam até o novo lugar, as outras desfocam para fora e para dentro.

- `phrases` (a primeira deve ser *Fullstack Developer*), `interval` em ms (3400 padrão). Aceita quantas frases quiser.
- Leitores de tela recebem todas as frases de uma vez, sem anúncios a cada troca. Com movimento reduzido, troca simples.
- Frases curtas (até ~24 caracteres) para caber numa linha no celular.
