# Statement

Frase de impacto grande que abre uma seção, revelada palavra a palavra ao entrar na tela.

- `children` é texto puro; `highlight` pinta palavras em `terracota-strong` (uma ou duas).
- `placeholder` deixa o texto em `ink-2` para marcar copy provisória. `label` + `index` desenham o SectionLabel acima.
