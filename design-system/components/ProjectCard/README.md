# ProjectCard

Card de projeto onde a imagem é protagonista: zoom lento, tooltip `VIEW ↗` seguindo o cursor, título que desliza com seta, regra inferior que acende em terracota.

- `size`: `feature` (7 col), `half` / `tall` (5 col) em `.mf-pgrid`; `.mf-proj--offset` desloca para criar ritmo.
- `href` (case study), `github`, `live` opcionais; `tech` vira tags. `images` aceita dois prints: o primeiro em repouso, o segundo aparece no hover com contador `01 / 02`. Sem imagem, mostra placeholder de interface.
