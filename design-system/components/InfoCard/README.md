# InfoCard

Card auxiliar pequeno com label mono, conteúdo e rodapé opcional — para Status, Resume, Location, Available for.

- `tone`: `paper` (padrão), `sand`, `deep`, `ink`. Combine tamanhos diferentes num grid (bento) ao redor do terminal.
- `mf-info__big` para o dado principal e `mf-info__muted` para o complemento.
