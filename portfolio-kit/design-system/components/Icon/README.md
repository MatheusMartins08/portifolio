# Icon

Ícone de traço fino (1.5px, grade 24px) que herda `currentColor`.

- `name` de `Icon.names`; `size` em px (16 padrão, 12–20 no uso real).
- Decorativo por padrão (`aria-hidden`); passe `label` quando o ícone for o único conteúdo.
- Não misture com outras famílias de ícones nem com logos coloridos.
