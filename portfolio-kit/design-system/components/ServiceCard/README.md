# ServiceCard

Card de serviço com numeral mono, label, motivo gráfico, título, descrição e destaques.

- Dois, e só dois: `01 WEB` (`motif="web"`, `size="lg"`) e `02 IA` (`motif="ai"`, `size="md"`) em `.mf-svc-grid` — 7/5 com o segundo deslocado.
- No hover: borda superior terracota, numeral acende, traços dos destaques crescem, e o motivo reage ao serviço (a interface se monta; o fluxo corre entre os nós).
