# Timeline

Timeline vertical alternando esquerda/direita, com trilho que se preenche em terracota conforme o scroll.

- `items`: título, org, tipo, período, local, resumo, `tags`, `details` (abre em *Ver atividades*), `current`. `future: true` desenha o capítulo ainda não iniciado (tracejado, apagado, *NEXT CHAPTER*).
- Cada item entra em etapas: ponto ativa, braço cresce, card aparece, conteúdo em 4 tempos.
- Funciona dentro de qualquer contêiner com scroll. Abaixo de 720px vira coluna única à esquerda.
