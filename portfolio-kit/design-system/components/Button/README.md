# Button

Botão ou link-botão; vira `<a>` quando recebe `href`.

- `primary` (terracota) é o CTA da tela — um por vista: *Let's talk*, *Enviar*.
- `solid` (ink) para ação forte secundária; `ghost` para *Download CV* e ações de apoio; `text` dentro de frases.
- `icon` com seta faz a seta atravessar o botão no hover. `loading` troca por spinner e desabilita.
- Texto em sentence case, verbo primeiro, até três palavras.
